# 公路车躲下水道（Drain Dodger）

一款基于 **Vite + TypeScript + 原生 HTML5 Canvas 2D + Web Audio API** 的第一人称伪 3D 竖屏公路车避障小游戏（Idea Lab v2 — Project 03）。

> **原始灵感摘要**（来自早期创意记录）：  
> 骑公路车时前轮前方就是道路排水井——竖屏第一人称视角下，车把位于画面底部，道路不断向玩家迎面移动；玩家通过左/右滑控制自行车避开排水沟、水坑等道路障碍，一旦撞上即翻车结束。

## 核心玩法与设计

- **第一人称公路车驾驶舱**：底部弯把（把带纹理、STI 手变头、码表与水壶架一角）随转向产生 `±14°` 倾角，并同步带动地面骑行者长影子与前轮着地基准点。
- **伪 3D 透视路面**：采用经典 OutRun / `javascript-racer` 扫描线透视投影（`scale = cameraDepth / dz`），左侧为白色车道分隔线与机动车道，右侧为高出路面的路缘石与人行道。
- **4 类差异化道路障碍**：
  - `||||` **竖缝下水道铁箅子（致命）**：顺着车轮纵向排列，细胎压中直接卡死翻车。
  - `====` **横纹排水格栅（安全可碾压）**：横向垂直于路面，碾压触发两次小颠簸“咯噔”与 `+10` 稳健碾压分，在夹缝中往往是唯一生路。
  - **积水滩 / 暗藏竖缝积水**：压上去暂降 30% 转向灵敏度 `0.6s`；中后期部分积水内暗藏半截竖缝铁箅子。
  - **左方汽车贴身超车**：红框鸣笛预警 `🚗 滴滴!` 1.1 秒后，车辆沿左侧机动车道贴白线呼啸超车，期间越线必撞。
- **公平生成与擦肩而过**：纯逻辑层强制校验每个 `Z` 窗口至少保留 `> 2.5 倍轮胎宽度` 的安全通道；贴边躲过致命竖缝触发 `好险！+30`。

## 操作方式

- **触屏 / 鼠标**：按住画布左半区 / 右半区连续向左/向右压弯转向；右上角可切换静音。
- **键盘**：`A` / `D` 或 `←` / `→` 连续转向；结算页按 `R` 或 `Enter` 一键再来一趟。
- **调试视图**：URL 后追加 `?debug=1` 可显示 `collisionZ` 碰撞线、有效轮胎宽度、障碍物/Near Miss 边界框与当前最宽安全通道。

## 目录结构

- `src/config/tuning.ts`：视口 `390×640`、固定步长 `1000/60`、伪 3D 相机参数、转向惯性、速度曲线与公平生成器阈值
- `src/game/rules.ts`：纯 TypeScript 透视投影、横向物理、障碍物/Near Miss 判定与公平波次生成器
- `src/game/world.ts`：路面条纹滚动、超车汽车状态机、颠簸震动、水花粒子与飘字管理
- `src/game/audio.ts`：Web Audio API 合成音效（横盖双响、水洼溅水、Near Miss、鸣笛“滴滴”、超车风声、翻车撞击）
- `src/render/painter.ts`：Canvas 2D 伪 3D 路面、高对比度横/竖格栅、第一人称弯把驾驶舱、HUD 与 `?debug=1` 叠层
- `src/main.ts`：DPR 自适应、左右半区按住指针控制、`localStorage` 最高分记录
- `tests/rules.test.ts`：Vitest 单元测试
